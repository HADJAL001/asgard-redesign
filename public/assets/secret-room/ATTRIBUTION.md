# Secret Room Assets

## HDRI environments

The six HDRI files in `hdr/` are 1K variants sourced from Poly Haven and are
available under CC0 1.0 Universal: https://polyhaven.com/license

- `studio.hdr`: Studio Small 09
- `gallery-studio.hdr`: Brown Photostudio 07
- `workshop.hdr`: Aerodynamics Workshop
- `mountain-daylight.hdr`: Kloofendal 48d Partly Cloudy
- `venice-sunset.hdr`: Venice Sunset
- `sunrise.hdr`: Spruit Sunrise

## GLB models

The models in `models/` are from Khronos glTF Sample Assets:
https://github.com/KhronosGroup/glTF-Sample-Assets

- `sheen-chair.glb` (Sheen Chair): CC0 1.0, Wayfair, LLC / Eric Chadwick.
- `velvet-sofa.glb` (GlamVelvetSofa): CC BY 4.0. Source attribution remains
  embedded in the model metadata; see the upstream model README.
- `glass-vase-flowers.glb` (GlassVaseFlowers): CC BY 4.0. Source attribution
  remains embedded in the model metadata; see the upstream model README.
