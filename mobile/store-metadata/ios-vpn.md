### VPN функционал
Приложение использует Network Extension (NEPacketTunnelProvider) для создания
VPN туннеля. Это легитимное использование для защиты приватности пользователя.

Для тестирования VPN:
1. Войти с демо-аккаунтом
2. Перейти на вкладку VPN
3. Выбрать сервер (например, Amsterdam)
4. Нажать кнопку подключения
5. Подтвердить добавление VPN конфигурации (системный диалог)

### Шифрование
Приложение использует WireGuard протокол с современным шифрованием:
- ChaCha20 для симметричного шифрования
- Poly1305 для аутентификации
- Curve25519 для обмена ключами

Это соответствует требованиям экспортного контроля (ECCN 5D002).
