## Data Safety (Google Play)

### Сбор данных
| Тип данных | Собирается | Передаётся | Цель |
|------------|------------|------------|------|
| Email | Да | Нет | Аутентификация |
| Имя пользователя | Да | Нет | Профиль |
| Данные об использовании | Да | Да (Sentry) | Аналитика ошибок |
| IP-адрес | Да | Нет | VPN подключение |

### Безопасность
- Данные шифруются при передаче (TLS 1.3)
- VPN трафик шифруется (WireGuard)
- Пользователь может запросить удаление данных

### Соответствие политикам
- Приложение НЕ собирает данные для рекламы
- Приложение НЕ передаёт данные третьим лицам для рекламы
- VPN НЕ логирует активность пользователя

## Примечания для ревью

1. **VPN функционал**: Приложение использует VpnService API для создания
   защищённого туннеля. Это легитимное использование для защиты приватности.

2. **Permissions**:
   - INTERNET — для работы приложения и VPN
   - FOREGROUND_SERVICE — для VPN сервиса в фоне
   - FOREGROUND_SERVICE_SPECIAL_USE — для VPN

3. **Шифрование**: Приложение использует WireGuard протокол с современным
   шифрованием (ChaCha20, Poly1305, Curve25519).
