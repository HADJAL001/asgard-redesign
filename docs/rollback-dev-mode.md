## Почему риск для мира низкий

Dev Mode устроен как **слой поверх**, а не фильтр по существующим экранам:

- Новые файлы (`app/dev/*`, `components/dev-mode/*`) обычный режим не читает.
- Стили живут под классом `.dev-mode` на `<html>` — без него не применяются.
- В общий экран (`components/project-workspace-view.tsx`) добавлены только
  ветки под `mode === "dev"`; в мире выполняется прежний код.
- Единственная правка, действующая на обе вселенные, — новый роут в
  `next.config.mjs` (COOP/COEP для `/dev/workspace/:id`), он аддитивен.

**Самое вероятное последствие ошибки:** сломан `/dev`, мир работает.
Тогда откат не срочный — можно чинить отдельным PR.

## Триггеры отката

Откатывать, если после выката:

1. Не открывается любой экран **мира** (`/`, `/projects`, `/forge`, `/wallet`).
2. В мире пропал подвал (Кузница, Маркет, Биржа) или изменилась палитра —
   признак, что класс `.dev-mode` залип глобально.
3. Vercel не собрал прод-деплой.
4. Всплеск ошибок в Sentry на экранах мира.

Если сломан только `/dev` — **не откатывать**, чинить точечно.

Прод возвращается сразу; история Git не трогается — потом можно спокойно
разобраться. **Это предпочтительный способ при инциденте.**

## Вариант B — откат в Git (когда нужно убрать код из `main`)

```bash
cd <репозиторий>
git fetch origin
git checkout main && git pull

# Отменить merge-коммит PR #162 (SHA взять из `git log --oneline -5`)
git revert -m 1 <SHA merge-коммита> --no-edit
git push origin main
```

`revert -m 1` отменяет весь влитый набор, оставляя историю целой —
никаких `push --force` в `main`.

Проверка после отката:

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://osgardnewworld.com/
```

Ожидаем `200` и видимый подвал с экономикой на главной.

## Проверка сразу после выката (2 минуты)

1. Мир цел: открыть `/projects` — артефакты, «Продано», «Доход», подвал на месте.
2. Студия работает: кнопка «Режим разработчика» → переход → `/dev`.
3. Возврат: «В мир OSGARD» → мир снова в своей палитре, подвал вернулся.
4. Прямая ссылка: открыть `/dev` в новой вкладке — подвала мира быть НЕ должно
   (именно здесь пряталась дыра, найденная на стенде).

Автопроверка чистоты режима — `scripts/dev-mode-leak-check.mjs`
(запускается против локального стенда, требует сессии).
